# RouteCraft

**An AI-powered travel planning service that generates personalized itineraries and adapts routes based on changing travel conditions.**

RouteCraft는 사용자가 입력한 여행 조건과 방문 희망 장소를 바탕으로 여행 일정을 구성하고, 조건이 변경되면 전체 일정을 다시 조정하는 AI 기반 여행 계획 서비스입니다.

## 📌 프로젝트 소개

자유여행을 준비할 때는 블로그, SNS, 지도 등 여러 곳에서 정보를 찾아야 하고, 장소 간 이동시간과 방문 순서, 특정 날짜의 필수 일정, 하루 일정 종료 시간 등을 직접 고려해야 합니다. 방문하고 싶은 장소가 많거나 여행 조건이 복잡할수록 일정을 구성하고 수정하는 데 많은 시간과 노력이 필요합니다.

RouteCraft는 이러한 불편을 줄이기 위해 **사용자가 지정한 장소와 여행 조건을 바탕으로 일정을 생성하고, 조건이 바뀌면 전체 일정을 재구성하는 것**을 목표로 합니다.

## 🎯 해결하고자 하는 문제

- 여러 플랫폼에 흩어진 여행 정보를 직접 찾아 조합해야 하는 번거로움
- 장소 간 이동시간과 방문 순서를 고려해 일정을 구성해야 하는 어려움
- 특정 장소 방문이나 숙소 복귀 시간 등 제약조건을 일정에 반영해야 하는 문제
- 장소를 추가·삭제하거나 조건을 바꿀 때 전체 일정을 다시 조정해야 하는 불편함

## ✨ 주요 기능

### 1. 여행 조건 및 방문 장소 설정
여행지, 여행 기간, 인원, 이동수단, 방문 희망 장소를 입력하고 특정 날짜의 필수 일정이나 하루 일정 종료 시간 등의 조건을 설정합니다.

### 2. AI 기반 여행 일정 생성
입력한 여행 조건과 방문 희망 장소를 바탕으로 날짜별·시간대별 여행 일정을 구성합니다. 장소 위치와 이동시간 등 실제 정보는 연동하는 지도·경로 API 또는 장소 데이터 등을 활용하는 방식으로 계획합니다.

### 3. 일정 변경에 따른 전체 일정 재구성
방문 장소를 추가·삭제하거나 여행 조건을 변경하면, 변경 내용을 반영해 기존 일정을 다시 구성합니다.

### 4. 시간대별 이동 동선 확인
생성된 일정에서 방문 장소, 방문 시간, 장소 간 이동시간을 시간순으로 확인할 수 있도록 합니다. 지도·경로 표시 기능은 사용할 API와 구현 범위에 따라 개발할 예정입니다.

## 🧭 사용 흐름

1. 여행지, 여행 기간, 인원, 이동수단을 입력합니다.
2. 방문 희망 장소를 추가합니다.
3. 특정 날짜 방문이나 숙소 복귀 시간 등 추가 조건을 입력합니다.
4. AI 일정 생성을 요청합니다.
5. 날짜별·시간대별 여행 일정을 확인합니다.
6. 장소나 조건을 변경한 뒤 전체 일정 재구성을 요청합니다.

## 🏗️ 시스템 구조(계획)

```text
사용자
  ↓
프론트엔드 UI
  ↓
백엔드 서버
  ├── 생성형 AI: 조건 분석, 일정 생성 및 재구성
  └── 지도·경로 API 또는 장소 데이터: 위치 및 이동시간 정보
  ↓
날짜별·시간대별 여행 일정 출력
```

※ 위 구조는 기획 단계의 설계안입니다. 실제 기술 스택과 외부 API는 개발 과정에서 확정합니다.
